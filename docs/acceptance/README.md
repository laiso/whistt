# Acceptance tests

Acceptance criteria are grouped by user-facing feature. Keep each case observable from outside the implementation and assign a stable ID so it can later map to an automated UI test.

| Area | Cases | Automated |
| --- | ---: | ---: |
| [Hotkeys](hotkeys.md) | 1 | 0 |

Use `manual` until a case is covered end to end. When automated, change its status to `automated` and add the test target and test name.
